# ⚖️ Regras de Negócio

## Objetivo

Este documento reúne todas as regras obrigatórias que governam o funcionamento do ARISE.

Essas regras representam restrições permanentes do sistema e devem ser respeitadas independentemente da implementação.

---

# Progressão

- O XP Geral nunca diminui.
    
- O XP das Categorias nunca diminui.
    
- O Nível Geral nunca diminui.
    
- O nível das Categorias nunca diminui.
    
- A especialização ocorre mais lentamente que a progressão geral.
    

---

# Quests

- Toda Quest pertence a pelo menos uma Categoria.
    
- Toda Quest possui uma dificuldade.
    
- Uma Quest só pode ser concluída uma única vez por ciclo.
    
- Quests recorrentes geram novas instâncias automaticamente.
    
- Quests expiradas são registradas no Histórico.
    

---

# Momentum

- Pode aumentar ou diminuir.
    
- É influenciado pela consistência do jogador.
    
- Nunca pode ser alterado manualmente.
    

---

# Afinidade

- Existe individualmente para cada Categoria.
    
- Pode aumentar ou diminuir.
    
- Influencia ganhos de XP e aplicação de Estados.
    

---

# Buffs e Debuffs

- Possuem persistência.
    
- Não desaparecem imediatamente.
    
- Devem respeitar suas condições de remoção.
    

---

# Status

- Apenas um Status permanece ativo por vez.
    
- O jogador não escolhe seu próprio Status.
    
- O Status é calculado automaticamente.
    

---

# Títulos

- Representam conquistas permanentes.
    
- Não são removidos após desbloqueados.
    
- Não possuem efeito mecânico direto.
    

---

# Contratos

- São opcionais.
    
- Após aceitos, não podem ser alterados.
    
- Possuem recompensas e consequências definidas previamente.
    

---

# Histórico

- Toda ação relevante deve ser registrada.
    
- O Histórico nunca deve ser alterado manualmente.
    

---

# Princípios Gerais

- O sistema deve privilegiar consistência.
    
- Nenhuma mecânica deve incentivar exploração do sistema.
    
- Todo cálculo deve ser determinístico.
    
- Toda recompensa deve possuir uma justificativa dentro do sistema.
