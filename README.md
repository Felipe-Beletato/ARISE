\# ⚔️ ARISE



> An RPG-inspired personal growth system that transforms real-life achievements into meaningful character progression.



\## 📖 About



ARISE is a personal productivity system designed as an RPG.



Instead of simply completing tasks, the player evolves through real-world actions, gaining experience, developing affinities, unlocking titles and building consistency over time.



The project focuses on making personal growth engaging without losing sight of reality.
