# Sistema de Progressão

## Objetivo

O Sistema de Progressão representa a evolução do jogador dentro do ARISE.

Toda evolução virtual deve refletir uma evolução no mundo real. O objetivo não é acumular XP de forma vazia, mas recompensar ações reais que geram desenvolvimento pessoal.

---

## Filosofia

O progresso é consequência da disciplina.

O jogador não deve buscar XP como objetivo principal. O XP é apenas uma representação visual da evolução.

O verdadeiro foco é consistência e melhoria contínua.

---

## Estrutura

A progressão é dividida em dois sistemas:

- XP Geral
- XP por Categoria

---

## XP Geral

Representa a evolução global do jogador.

Usado para calcular o Nível Geral.

É obtido por qualquer Quest concluída.

---

## XP por Categoria

Cada Categoria possui seu próprio XP.

Representa evolução em áreas específicas da vida.

Ex:

- XP Vanguard
- XP Codex
- XP Soul
- XP Treasury
- XP Creation

---

## Nível Geral

Calculado exclusivamente pelo XP Geral.

Segue uma curva progressiva (exponencial suave).

Níveis iniciais são rápidos para gerar motivação.

Níveis avançados representam consistência.

---

## Níveis de Categoria

Cada categoria possui seu próprio nível.

Calculado apenas com XP daquela categoria.

Exibe especialização do jogador.

---

## Curva de Progressão

A progressão segue curva crescente.

Cada nível exige mais XP que o anterior.

Valores exatos definidos em [[Balanceamento]].

## MVP

- XP Geral funcional
- XP por Categoria armazenado
- Nível Geral funcional

---

## Decisões

- XP Geral e XP de Categoria são separados
- Nível é cálculo do XP
- XP não deve incentivar comportamento prejudicial
